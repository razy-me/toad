toad Entwickler-Wiki

Eine deklarative Design-Sprache, die strukturierte Layouts in pixelgenaue Multi-Scale-Bilder (PNG/JPG/WebP/SVG) und native, editierbare Photoshop-Dateien (.psd) kompiliert. Dezentral über toad <name> von jedem Ordner aus nutzbar.

1. Schnellstart, Projekt-Initialisierung & CLI

Mit toad init erstellst du in Sekunden ein neues, sofort einsatzbereites Design-Projekt (inkl. automatischer Projekt-Nummerierung, Starter-Template und package.json). Der Compiler liest die in der Datei definierten Export-Optionen (Formate, Presets, Seitenverhältnis, Auflösung) automatisch aus. Ein einfacher Aufruf reicht:

Terminal (PowerShell / Bash / CMD) 
# 1. Neues Projekt scaffolden (erstellt z.B. toad-project-1/ mit main.toad & package.json)
toad init

# Oder mit individuellem Projektnamen:
toad init mein-banner

# 2. Dateiname ohne Extension aufrufen — gestaffelte, tiefenbegrenzte Suche findet das Dokument automatisch
toad logo
toad social_card

# 3. Bestimmte Formate exportieren (Komma oder Leerzeichen als Trenner)
toad logo -f svg
toad logo -f "svg, png, psd"
toad logo -f all -s 2

# 4. Statische Code-Analyse & Linter
toad lint logo

# 5. Automatischer Code-Formatter (Alias: toad format)
toad fmt logo

# 6. Live-Preview mit Browser Hot Reload (kein F5 nötig)
toad logo -w

# 7. In bestimmten Ordner exportieren
toad logo -o ./dist
toad logo -o .    # in aktuellen Terminal-Ordner

toad init [name]

Scaffoldet ein schlüsselfertiges Projekt mit Starter-Template und npm-Scripts für dev und build.

Gestaffelte Namenssuche

lint, format & Co. akzeptieren den bloßen Dokumentnamen — eine gestaffelte, tiefenbegrenzte Ordnersuche findet die Datei.

Plattform-Presets

Direkte Unterstützung von preset: og-image;, preset: instagram-story; etc. im canvas.

-w, --watch

Reagiert live auf Änderungen via SSE. Enthält interaktive Zoom-Controls und einen 1-Klick-Button zum direkten Öffnen des Datei-Ordners im Explorer.

Format-Flag Was wird exportiert
-f png PNG mit voller Alpha-Transparenz
-f jpg Komprimiertes JPEG (Qualität via -q 90)
-f webp Modernes komprimiertes WebP
-f svg Skalierbare Vektor-SVG
-f psd Nativer Photoshop-Layer-Stack mit Vektor-Masken & Textebenen
-f image Shortcut: PNG + JPG + WebP + SVG gleichzeitig
-f all Alles: PNG + JPG + WebP + PSD + SVG gleichzeitig
-f "svg, png, psd" Beliebige Kombi (kommagetrennt oder mit Leerzeichen)

2. Dateistruktur, Canvas & Plattform-Presets

Jede .toad-Datei definiert am Anfang den canvas-Block. Hier legst du Plattform-Presets, Seitenverhältnis, Ziel-Auflösung, Exportformate und Hintergrund fest:

banner.toad 
@import "./tokens.toad";
@font "./fonts/Inter.ttf" as "Inter";

// Option A: Sofortiges Social-Media & Web-Preset
canvas "OpenGraph-Image" {
  preset: og-image;            // 1200x630 (auch: twitter-header, instagram-post, instagram-story, youtube-thumbnail)
  export: all;                 // Exportiert PNG, JPG, WebP, SVG und PSD
  background: #0f172a;
}

// Option B: Dynamisches Seitenverhältnis & Auflösung
canvas "Brand Identity" {
  ratio: 16:9;                 // '16:9', '1:1', '9:16', '4:5', '21:9', etc.
  resolution: 1080p;           // Presets: sd, hd, fhd, 1080p, qhd, 4k, 8k
  export: image;               // Macros: 'all' oder 'image' (png, jpg, webp, svg)
  quality: 85%;                // entspricht: compress: 15%;
  background: transparent;     // Volle Alpha-Transparenz
}

// Option C: Feste Pixel-Dimensionen
canvas "Custom Banner" {
  width: 1200px;
  height: 630px;
  export: png, webp;
  background: #0f172a;
}

// Option D: Druckvorstufe, CMYK & Schnittmarken
canvas "Business-Card" {
  size: 85mm 55mm;             // Print-Einheiten: 'mm', 'cm', 'in', 'pt'
  dpi: 300;                    // Ziel-Druckauflösung (Standard: 96)
  bleed: 3mm;                  // Beschnittzugabe um die Trim-Box
  crop-marks: true;            // Schnittmarken & Passkreuze rendern
  color-mode: cmyk;            // 'cmyk' Farbmodus
  background: cmyk(0, 0, 0, 0.05);
}

// Option E: Multi-Canvas (Mehrseitige Dokumente)
canvas "Front" {
  size: 85mm 55mm;
  rect "logo" { at: 20mm 15mm; size: 40mm 20mm; fill: #38bdf8; }
}

canvas "Back" {
  size: 85mm 55mm;
  rect "qr" { at: 30mm 15mm; size: 25mm 25mm; fill: #0f172a; }
}

5. Text, Typografie & Kerning

Texte werden über die Skia-Engine millimetergenau ausgemessen und in Photoshop als echte, editierbare Textebenen exportiert.

typography.toad 
text #headline {
  at: (80px, 120px);
  size: 600px;                  // Feste Breite aktiviert automatischen Wortumbruch
  content: "toad Compiler: Die Zukunft des deklarativen Designs.";
  
  font-family: "Inter";
  font-size: 36px;
  font-weight: 700;             // 100-900 oder 'bold', 'normal'
  line-height: 1.25;
  letter-spacing: 1.5px;        // Tracking / Kerning (auch: tracking: 1.5px;)
  text-transform: uppercase;    // 'uppercase', 'lowercase', 'capitalize', 'none'
  font-features: "liga" 1, "smcp" 1; // OpenType-Features (Ligaturen, Kapitälchen)
  font-variation: "wght" 700 "wdth" 85; // Variable Font Achsen
  align: justify;               // 'left', 'center', 'right', 'justify'
  hanging-punctuation: true;    // Optischer Randausgleich für Satzzeichen
  color: #ffffff;
}
Tipp zu OpenType, Blocksatz & Zeilenumbruch

Wird align: justify oder font-features gesetzt, berechnet die Skia-Engine den Wort- und Glyphenabstand präzise und exportiert die Absätze direkt als formatierte Photoshop-Textlayer.

6. Positionierung, Math-Solver & calc()

Positioniere Elemente relational oder nutze mathematische Berechnungen direkt im Code:

#title (Referenz-Element)
at: below #title offset 16px
#subtitle (Folge-Element)
positioning_and_math.toad 
// 1. Relationale Positionierung
at: below #headline offset 20px;
at: right of #avatar offset 12px;
at: inside #card offset 20px;
at: center of canvas;

// 2. Dynamische Math-Berechnungen (calc)
rect #fluidBox {
  size: calc(100% - 60px) calc(50% + 20px);
  fill: #1e293b;
}

// 3. Margins & Ebenen-Reihenfolge (2D-Offsets gehören in at:, z.B. at: below #id offset -20px;)
rect #offsetItem {
  margin: 16px 24px;          // Außenabstand
  z-index: 10;                // Ebenen-Reihenfolge
}

10. Layout-Container (Stack mit Hug/Fill, Grid & Gruppen)

Auto-Layout Stack mit 'hug' und 'fill'

Ordnet Kindelemente automatisch vertikal oder horizontal mit konfigurierbarem gap und padding an. Mit hug passt sich die Container-Größe an den Inhalt an, während fill den restlichen Platz ausfüllt:

stack.toad 
stack #navigationBar {
  at: (40px, 40px);
  size: 800px hug;             // 'hug' schrumpft/wächst automatisch mit den Kindern
  direction: horizontal;       // 'horizontal' oder 'vertical'
  align: center;               // Cross-axis: 'start', 'center', 'end'
  gap: 16px;
  padding: 12px 24px;
  fill: #1e293b;
  radius: 24px;
  
  rect { size: fill 40px; fill: #334155; radius: 8px; } // 'fill' füllt restlichen Platz
  text { content: "Home"; font-weight: 700; color: #38bdf8; }
}

Gruppen (Groups) & Grid

12. Native Photoshop (.psd) Bearbeitbarkeit

Beim Export nach PSD (export: psd; oder toad datei -f psd) generiert der Compiler keine flachen Pixel-Raster, sondern echte, native Photoshop-Strukturen:

Live-Vektor-Formen

Rechtecke, Kreise, Polygone und Pfade werden als Formebenen mit Bézier-Ankerpunkten angelegt. Verlustfrei transformierbar (Strg+T).

Live-Eckenrundung

Eckenrundungen von Rechtecken lassen sich im Photoshop Eigenschaften-Bedienfeld (Properties) nachträglich über 4 separate Regler verändern.

Vektor-Verläufe

Linear- und Radial-Gradients öffnen direkt den nativen Photoshop Verlaufs-Editor mit Farbstopps, Deckkraftstopps und Winkelrad.

fx-Ebenenstile (Layer FX)

Schatten (shadow:, inner-shadow:), Schein (glow:, inner-glow:), Kantenrelief (bevel:), Kontur (stroke-style:) und Überlagerung (overlay:) werden als native Photoshop Layer FX mit fx-Badge angelegt.

Editierbarer Text

Echte Photoshop Type Layers mit PostScript-Schriftart, Schriftgröße, Zeilenabstand (Leading) und Ausrichtung (inkl. Blocksatz / Justification). Editierbar mit dem Textwerkzeug (T).

Schnittmasken & Ordner

clip: true; wird als native Photoshop Schnittmaske angelegt. Gruppen und Stacks werden zu hierarchischen Ebenen-Ordnern.

13. Komplexe Praxis-Beispiele (Masterclass)
